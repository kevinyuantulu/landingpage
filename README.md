# HabitBuster landing page

A responsive MVP built with plain HTML, CSS, and JavaScript. No dependency installation or build step is required.

Run `node server.cjs` and open http://127.0.0.1:4173, or open `index.html` directly.

The supplied shield logo and actual app screenshots are stored in `assets/`. The dashboard appears in the hero; both the dashboard and device settings are shown in the screenshot gallery. Click either gallery screenshot to view it at full size. The wearable and board remain labeled concept illustrations. The reminder selector is an interactive explanation and does not connect to hardware.

The page uses working section links. A demo request channel can be added when its contact destination is confirmed.

## Repository structure

- `index.html`, `styles.css`, `script.js`: website source.
- `assets/`: logo and app screenshots used by the website.
- `server.cjs`: optional local preview server.
- `docs/MVP-DESIGN.md`: first-release design scope.
- `docs/DESIGN.md`: broader design reference for future expansion.

The repository itself is the complete website folder; no separate export copy is needed.
